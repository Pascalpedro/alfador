# Add Real Photography Across the Alfador Website

## Goal
Place real, realistic-style photos in the key visual slots of the site so pages feel alive and trustworthy, while keeping the existing midnight-blue / electric-blue design system untouched.

## Step 0 — Photos from you (needed before build)
Attach the photos to the chat (drag-and-drop or the + button). For each slot below, one photo is needed. Wide landscape photos (roughly 16:9 or wider) work best for heroes; anything you have is fine for the smaller slots.

| # | Slot | Ideal subject |
|---|------|---------------|
| 1 | About page hero banner | Your team at work, office, or an infrastructure scene |
| 2 | About "Why Alfador" section | Engineers collaborating, whiteboard, client meeting |
| 3 | Solutions page hero banner | Server room / network rack / cabling |
| 4–7 | Solutions: Network, Cloud, Security, Smart Spaces sections | Matching scene per service (racks, cloud data centre, cameras/access control, smart building) |
| 8 | Contact page hero banner | Office front, meeting room, or support desk |
| 9 | Homepage supporting image | Field work, installations, or team photo |

You don't need perfect coverage — send whatever you have and mark which page each photo is for. Any slot without a photo stays as-is (no placeholder filler).

## Step 1 — Prepare and place the photos
- Save each photo into the project's asset folder, lightly colour-graded toward the site's navy/blue palette where it helps consistency (no heavy filters).
- **Page heroes (About / Solutions / Contact):** add the photo as a banner behind the existing page title with a deep-navy overlay so white text stays fully readable. Text, buttons, and layout otherwise unchanged.
- **About storytelling:** place the "Why Alfador" photo in the right-hand column beside the copy (desktop), stacked above the checklist on mobile.
- **Solutions service sections:** add a wide thumbnail image at the top of each service section that has one, beside the section number/title.
- **Homepage:** place the supporting photo near the industries/benefits area in the existing card style (rounded, bordered, soft shadow).

## Step 2 — Responsive and performance
- Every image: responsive scaling, `loading="lazy"` (heroes eager-loaded), descriptive alt text, and sizing that looks correct on mobile and desktop.
- No layout shift; existing sections, copy, anchors, and CTAs untouched.

## Step 3 — Verification
- Check all pages (Home, About, Solutions, Contact) in the preview at desktop and mobile widths.
- Confirm hero text contrast over the new banners, and that no console errors appear.

## Notes
- Projects and Insights pages stay disabled as previously requested.
- If you'd rather I generate any missing photos in a realistic photography style, say so and I'll fill those slots.
